# BugSnag (SmartBear)

> BugSnag is an application stability monitoring platform from SmartBear — error
> monitoring, real user monitoring and distributed tracing for web, mobile,
> desktop and back-end applications. It ships six public REST APIs, a hosted MCP
> server, a CLI, and notifier SDKs for 50+ platforms.

## APIs

Six OpenAPI 3.0 definitions, published by SmartBear on SwaggerHub under the
`smartbear-public` organization.

- [Data Access API v2](https://api.swaggerhub.com/apis/smartbear-public/bugsnag-data-access-api/2/swagger.json): 141 operations on https://api.bugsnag.com — errors, events, projects, organizations, collaborators, teams, releases, span groups, traces, feature flags, saved searches, and a SCIM 2.0 provisioning surface. Auth: `Authorization: token <PERSONAL_AUTH_TOKEN>`.
- [Error Reporting API v1](https://api.swaggerhub.com/apis/smartbear-public/bugsnag-error-reporting-api/1/swagger.json): event ingest on https://notify.bugsnag.com — `POST /` for error reports, `POST /minidump` for crash minidumps. Auth: `Bugsnag-Api-Key` header.
- [Session Tracking API v1](https://api.swaggerhub.com/apis/smartbear-public/bugsnag-session-tracking-api/1/swagger.json): session ingest on https://sessions.bugsnag.com, the input to stability scores.
- [Trace API v1](https://api.swaggerhub.com/apis/smartbear-public/bugsnag-trace-api/1/swagger.json): OTLP/HTTP span ingest on https://otlp.bugsnag.com — `POST /traces/v1` takes an OpenTelemetry ExportTraceServiceRequest.
- [Build API v1](https://api.swaggerhub.com/apis/smartbear-public/bugsnag-build-api/1/swagger.json): release/deploy notification on https://build.bugsnag.com.
- [Upload API v1](https://api.swaggerhub.com/apis/smartbear-public/bugsnag-upload-api/1/swagger.json): 10 symbol and mapping upload endpoints on https://upload.bugsnag.com — dSYM, ProGuard, NDK, Breakpad, Dart, Linux, Nintendo Switch, React Native, JavaScript source maps, Unity line mappings.

## Agent surfaces

- Remote MCP server: `https://bugsnag.mcp.smartbear.com/mcp` — OAuth 2.1 (authorization code + PKCE S256, dynamic client registration) against https://oauth.bugsnag.com. 19 tools and one resource covering error triage, event detail, releases and performance.
- Local MCP server: `npx -y @smartbear/mcp@latest`, authenticated with `BUGSNAG_AUTH_TOKEN`.
- [MCP integration guide](https://developer.smartbear.com/smartbear-mcp/docs/bugsnag-integration)
- Discovery documents: `/.well-known/oauth-protected-resource` on the MCP host (RFC 9728) and `/.well-known/oauth-authorization-server` on oauth.bugsnag.com (RFC 8414). No security.txt, api-catalog or agent card is served on any BugSnag host.

## Things an agent should know before writing

- There is no idempotency key on any BugSnag API. A retried write can duplicate.
- There is no dry-run or preview mode.
- Error `discard` is reversible with `undiscard`; `delete` operations are not, and no retention window is published.
- Errors are plain JSON, not RFC 9457 problem+json, and carry no machine-readable error code.
- `429` is documented on the portal but is declared on none of the 141 Data Access operations in the OpenAPI.
